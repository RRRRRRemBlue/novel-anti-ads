点击不跳走、不弹窗、不自动跳转，只留正文和翻页。

1先说清楚它是怎么拦的

不靠"猜它把广告写在哪"，而是守住「出站」这一个关口——任何要离开本站的跳转，一律拦下。所以站点改版也不会失效。

它的花招怎么挡
透明链接铺在正文上，点哪都跳点击瞬间判定目标域名
window.open 弹新标签直接返回空，不给弹
几秒后自动 location.href=…导航级取消（关键）
meta refresh / 外站 iframe取消导航 + 移除节点
广告位、全屏透明遮罩直接清掉

核心用的是浏览器官方的 Navigation API：网页任何跳转动作发生前都会先"打报告"，我们把它拦下来。这是目前唯一能真正取消一次跳转的办法。

2安装（就用你现在的手机 Edge）

好消息 安卓版 Edge 从 v134 起已经自带扩展商店，里面就有 Tampermonkey。不用换浏览器。

  1. 到应用商店把 Edge 更新到最新版（旧版本没有扩展商店）。
  2. 打开 Edge，点底栏中间的 菜单（≡） → 扩展。
  3. 找到 Tampermonkey → 点 获取 / Add 装上。
  4. 回到这个页面，点下面的按钮复制脚本。
  5. 打开 Tampermonkey 面板 → 点 + 新建脚本 → 全选删除 → 粘贴 → 保存（右下角磁盘图标）。
  6. 打开小说页面，右下角会出现一个半透明盾牌图标 = 生效了。

粘贴时如果提示"检测到新脚本"，点是即可。装好后可以顺手把这个页面收藏掉。

3验证一下

  • 打开任意章节，随手在正文上点几下 —— 页面不应该跳走或弹新标签。
  • 点右下角盾牌图标，能看到"已拦截 N 次外部跳转"和具体拦截记录。
  • 点「下一章」—— 必须正常翻页（同站链接是完全放行的，这条已验证）。
  • 阅读时嫌那个盾牌碍事？打开面板取消勾选「显示这个悬浮球」即可。

?常见问题

装了还是会被跳走？

先点盾牌图标确认「拦截点击 / 弹窗 / 强制跳转」是勾上的。如果仍然跳，点面板里的「复制诊断信息」，把内容发我，我来加规则。

换域名 / 换书站了怎么办？

打开 Tampermonkey 里这个脚本，找到最上面这几行：
const SITES = [ 'renrenreshu.com' ];
把你现在访问的域名加进去（一行一个，不要写 http:// 和 www.），保存即可。脚本对任何小说站都通用。

会不会影响正常翻页和看书？

不会。判定规则是「只拦站外」：同域名、同主域、相对路径的链接一律放行。下一章/目录 这些全部正常。

正文被误删了 / 广告没清干净？

面板里把「清理广告位与外站 iframe」关掉试试。这条是按 id/class 关键词清理的，个别站点可能误判，关掉不影响防跳转。

想临时放行一次外链怎么办？

面板里取消勾选「拦截点击 / 弹窗 / 强制跳转」，看完再勾回来（勾回来会自动恢复被冻结的链接）。

为什么有时候右下角什么提示都没有？

大多数跳转在导航层就被取消了，页面根本不会反应，提示条只是给你一个"刚才拦了一次"的反馈。可以关掉「拦截时显示提示」。
